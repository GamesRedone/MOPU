1. THE APPLICATION

MOPU is a piece of software created to keep a user's custom Mod
Organizer 2 ("MO2") profile aligned with changes made by a modlist's author over
time, without requiring the user to manually track or re-apply those changes by
hand, and without disturbing customizations the user has made to their own profile.

Given a modlist repository hosted by its author on GitHub, a base profile within
that repository, a version the user's profile is currently based on, and a version
the user wishes to update to, the Software compares the two official versions of
that profile and applies the differences it identifies — including mods
added, removed, or renamed by the modlist author, and changes to a mod's default
enabled or disabled state — to a copy of the user's profile.

The Software modifies only three files associated with an MO2 profile:
modlist.txt, plugins.txt, and loadorder.txt.
It does not install, download, modify, or delete any mod files, archives, or other
content referenced by those files. The Software does not modify the user's
original profile in place; all output is written to a separate location of the
user's choosing for the user's own review before use.

The Software requires an internet connection solely to retrieve modlist version
data from a GitHub repository address supplied by the user, and performs no other
network communication.
